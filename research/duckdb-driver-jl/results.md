# DuckDB.jl 1.5.2 — benchmark results

Generated by `run_all.jl merge`. The deliverable is the per-cell path
**ordering**, which is stable across runs; absolute times are indicative and
machine-specific (goal.md constraints).

**Absolute times below are from a single repeat per thread configuration**,
not an average over the 12 runs merged here. `raw/*.json` is
sorted by filename and the first value seen for each path is the one
reported, so the `-a` run supplies every number in the tables — for no
better reason than that `a` sorts before the other tags. The remaining
repeats feed only the ordering-stability table at the end of this file;
they never average or widen the figures.
